# 项目类型与探索入口

用此表选择调查问题，随后核对真正的读取者与调用链。一个仓库可以属于多种类型，不为目录名自动分配职责。

| 场景 | 优先证据入口 | 贯穿例子与必须讲清的边界 |
|---|---|---|
| Web/业务服务 | 路由注册、启动函数、依赖注入、客户端调用、持久化、配置读取 | 一次具体请求；输入字段、身份、事务、响应；HTTP 成功与业务成功分别解释 |
| 微服务/monorepo | 工作区与构建配置、协议IDL、服务注册、消息订阅、部署单元 | 一个跨服务对象；同步与异步、关联ID、生产开关、外部仓库、失败重试 |
| SDK/库 | 公开API、示例、调用者、核心实现、测试 | 一次API调用；调用方负责什么、库内部做什么、扩展点、异常与兼容性；库不一定有“服务启动” |
| CLI/构建工具 | 命令注册、参数解析、主函数、配置解析、子进程、退出码 | 一条真实命令；shell、程序与子进程分工，cwd、stdout/stderr、文件变化、退出条件 |
| 插件/Agent/配置工程 | manifest读取器、技能入口、Prompt加载、宿主适配、部署客户端 | 安装或创建角色，再提交任务；文字方法、工具配置、运行机制分别解释；外部宿主代码可能不在仓库 |
| 前端/移动端 | 应用入口、页面路由、用户事件、状态存储、请求客户端、渲染 | 一次用户操作；本地状态、网络结果、可见界面、失败展示；构建产物不等于线上页面 |
| 数据管道 | DAG/任务注册、调度、输入表、转换、检查、输出/水位 | 一批带日期的数据；行粒度、字段前后变化、依赖、重跑、迟到数据、数据质量 |
| ML/模型服务 | 数据处理、训练入口、artifact保存与加载、推理入口、实验配置 | 一个样本从输入到预测；训练/推理、模型版本、feature schema、阈值、服务包装；训练成功不证明线上效果 |
| IaC/部署/运维 | Terraform/Helm/K8s定义、渲染、plan/apply或发布步骤、环境配置 | 配置如何成为计划与实际资源；声明、生成结果、执行记录、集群生效分别说明 |
| Legacy/多语言/代码生成 | public接口、构建依赖、FFI/JNI/RPC边界、schema、生成器 | 一次穿过语言边界的调用；类型、编码、序列化、线程、内存与错误转换 |
| 文档/研究/教学仓库 | 内容目录、引用、生成脚本、可执行示例 | 一份材料怎样变成产物；没有运行时则不强造启动流程，概念结论与实验证据分开 |

混合工程先画执行边界，再按每段机制选入口。例如一个 Python SDK 可能将任务交给 Node 子进程，而 Node 再访问云服务；包的实现语言不等于整个任务在哪里执行。

仅 GitHub URL 或片段可用时，先取得指定版本和可访问内容。无法访问仓库则清楚限定片段讲解，继续梳理输入/动作/输出；不编造目录、调用链或缺失源码。是否克隆到哪里遵循用户授权与宿主约定。

Notebook 需要区分代码单元、保存的输出、当前内核状态；生成代码与原始schema分别定位；外部配置或产品文档只能证明对应来源陈述，不证明该仓库当时的运行行为。
