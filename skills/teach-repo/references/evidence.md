# 证据与产物

## 交付结构按任务大小选择

小仓库或单条链路，一份 `GUIDE.md` 可以承载完整讲解。大型仓库使用学习入口、系统地图、主线教材与必要模块章节；入口给出顺序、学习目标与深读链接，而不是所有文件的平铺列表。图与素材置于输出目录的本地子目录。HTML/PDF是可选阅读形式，遵循用户格式要求，不强制生成多份副本。

持久教材的 `evidence.json` 保存关键机制结论，供脚本核对和后续更新。范围较宽时另存 `coverage.json`，至少包含本次目标、系统范围、已探索模块、状态/缺口、外部边界和下一轮问题。盘点输出可单独保存为 `inventory.json`，但它不是教学的证据结论清单。

正文的源文件链接放在已解释机制之后。重要缺口写在受影响的机制附近，全面证据清单放在查阅部分，避免让初读者先阅读审计表。

## evidence.json 格式

`schema_version` 当前为 1。下面是可复现测试用小仓库的结构，实际路径、行号、哈希与 revision 必须取自本次源码，不能复制示例值作为有效证据。

```json
{
  "schema_version": 1,
  "repository": {"revision": null},
  "claims": [{
    "id": "transform",
    "statement": "run 将输入 value 增加 1 后返回",
    "level": "source",
    "sources": [{
      "path": "src/main.py",
      "line_start": 1,
      "line_end": 2,
      "sha256": "这里填写源文件完整字节的 SHA-256"
    }]
  }]
}
```

`path` 相对于 `--repo` 指定根目录，范围不得越出仓库。行号为1起始、闭区间；哈希绑定整个文件的实际字节。仓库有Git时记录当前 HEAD，非Git或无法取得时为null并说明。工作区可能有未提交修改，因此内容哈希与 revision 都要保留。

结论等级：
- `documentation`：README、配置注释、设计说明等陈述。
- `source`：读取实际实现，确认条件、字段与调用。
- `test`：实际执行了限定测试，保留执行记录和输入范围。
- `runtime`：实际观测限定执行，保留环境、时间、运行标识及记录。
- `inference`：从已确认事实推导，正文明确推断与条件。
- `unknown`：当前无法判定，填写 `reason`，不是负面结论。

有来源的结论使用 `sources` 数组。测试/运行记录若在教学输出目录中，可设置 `kind: "artifact"`，路径相对于主文档所在目录；源码与记录分开保存，不复制真实敏感日志到交付物。来源默认为仓库文件。

`test` 与 `runtime` 还需要 `run` 对象：`id`、`timestamp`、`environment` 三个非空字段。至少有一个 `kind: "artifact"` 的执行记录来源。这些字段与哈希仅用于可追溯性，脚本不能认证记录真实性，也不能判断一次测试是否足以支持结论。部署、配置读取、请求执行和生产验收保留为不同结论。

文档引用行号发生变化、哈希失配或 HEAD 变化时重新核对；不要只更新哈希让旧结论看起来通过。来自网络文档的结论使用正文链接并注明版本，保存关键机制对应的本地来源或按用户约定提供可核查引用；本脚本不联网校验远端页面。

## 静态核对工具

```bash
python3 <本技能目录>/scripts/check_lesson.py --repo /path/to/repo --lesson /path/to/GUIDE.md --evidence /path/to/evidence.json
```

JSON结果写到stdout；通过返回0，检查失败返回1，输入错误返回2。检查字段、来源路径、行号、哈希、HEAD、Markdown本地文件链接及代码块闭合。支持本地文件链接的 `路径:行号` 形式，并核对该行存在；远端链接和章节锚点不联网或自动验证。默认检查主文档；多章时对涉及章节分别运行同一个工具，或按项目已有链接检查方式核对整套产物。图片和图的渲染仍需要另外观察。

source/test/runtime 等级不由脚本自动判断正确；自动通过只能说明记录和引用的结构可核对。是否易懂、是否解释必要前提、源码是否支持该语义、运行范围是否匹配，需要人工或独立试讲审阅。

渲染不可用时明确未验证渲染；不要绕过浏览器协议、文件或权限限制。向用户交付已完成教材、准确的验证范围和未完成项。静态检查结果不能替代读者反馈。
